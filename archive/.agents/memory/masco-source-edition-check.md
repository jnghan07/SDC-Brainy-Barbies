---
name: MASCO source edition check
description: A source-integrity issue found while checking the DOSM MASCO reference download.
---

The DOSM reference-download page labels the MASCO download link as the 2020 edition, but the PDF served by that link identifies itself as a 2013 classification. Do not cite the link as MASCO 2020 without rechecking the file contents and resolving the version mismatch.

**Why:** A current-looking official catalog entry can point to an outdated occupational classification, which would misstate the evidence basis for role records.

**How to apply:** Before using MASCO as support for occupational titles or duties, confirm the edition printed in the document itself and use a matching stable source URL.
